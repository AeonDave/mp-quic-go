# Security Policy

mp-quic-go is under active development. There may be problems in the protocols it implements,
or mistakes in the implementation. Security vulnerabilities are taken very seriously:
if you discover a security issue, please report it right away.

## Reporting a Vulnerability

If you find a vulnerability that may affect live deployments -- for example, by exposing
a remote execution exploit -- please [**report it privately**](https://github.com/qoke/mp-quic-go/security/advisories/new).
Please **do not file a public issue**.

If the issue is an implementation weakness that cannot be immediately exploited, or affects
something that is not yet deployed, it can be discussed openly.

Vulnerabilities in code inherited from [quic-go](https://github.com/quic-go/quic-go) should also be
reported to the quic-go project.

## Reporting a non-security bug

For non-security bugs, please file a GitHub [issue](https://github.com/qoke/mp-quic-go/issues/new).
